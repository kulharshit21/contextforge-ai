# Community Code of Conduct

ContextForge welcomes contributors with different backgrounds and experience levels. Be constructive, respectful, and patient in discussions.

- Discuss code and ideas, not personal characteristics.
- Offer actionable feedback, assume good intent, and acknowledge uncertainty.
- No harassment, discrimination, threats, doxxing, spam, or unwanted solicitation.
- Never share anyone else's secrets or sensitive material.
- Follow repository policies and GitHub's Terms of Service.

Maintainers may edit, hide, or remove abusive comments and restrict participation when necessary. Report conduct problems privately to the repository maintainer via their GitHub profile; do not post identifying information in a public issue.

These expectations apply to issues, pull requests, discussions, and other official project spaces.
